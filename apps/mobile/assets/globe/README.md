# Dotted globe

Original dot rendering generated by `node scripts/generate-globe.mjs`.
`land.geojson` is Natural Earth's public-domain 1:110m land geometry:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Natural Earth terms: https://www.naturalearthdata.com/about/terms-of-use/
The globe PNG is bundled locally. It makes no external requests.

The generator also writes `sphere.png` (the shaded sphere without dots) and
`points.json` (land/ocean points on the full sphere). The login screen draws
these points with Expo GL and rotates the sphere once every 45 seconds.
The home screen keeps the static PNG. Reduced Motion uses the static globe;
animation releases its graphics resources when login loses focus or the app
goes into the background.
